# 菜單資料格式規格

## 1. 為什麼需要統一資料格式

系統需要用同一種內容結構表示所有菜單。未來無論來源是人工建立、菜單圖片或一頁式 PDF，AI 辨識結果都必須先轉換並驗證為此格式，才能交給系統使用。

統一格式能讓點餐網站只負責讀取及顯示資料，不必因餐廳或菜單版面不同而重新製作網站，也能讓後續的編輯、驗證與儲存流程使用相同欄位定義。此格式只描述「菜單內容」，菜單屬於哪個團購或店家則由資料庫關聯管理。

## 2. 整體結構

JSON 根物件包含以下兩個必填欄位：

| 欄位 | 型別 | 必填 | 用途 |
| --- | --- | --- | --- |
| `restaurant` | object | 是 | 保存餐廳基本資料。 |
| `categories` | array | 是 | 保存菜單分類，陣列內每一項皆為分類物件。 |

## 3. 欄位說明

### 3.1 餐廳物件 `restaurant`

| 欄位 | 型別 | 必填 | 用途與規則 |
| --- | --- | --- | --- |
| `name` | string | 是 | 餐廳顯示名稱；不可為空字串。 |

### 3.2 分類物件 `category`

每個 `categories` 陣列元素均須包含以下欄位：

| 欄位 | 型別 | 必填 | 用途與規則 |
| --- | --- | --- | --- |
| `id` | string | 是 | 分類的穩定識別碼；使用小寫英文字母及連字符，例如 `rice-dishes`。 |
| `name` | string | 是 | 顯示給使用者看的分類中文名稱；不可為空字串。 |
| `items` | array | 是 | 此分類內的餐點陣列；陣列元素皆為餐點物件。 |

### 3.3 餐點物件 `item`

每個 `items` 陣列元素均須包含以下欄位：

| 欄位 | 型別 | 必填 | 用途與規則 |
| --- | --- | --- | --- |
| `id` | string | 是 | 餐點的穩定識別碼；使用小寫英文字母及連字符，例如 `braised-pork-rice`。 |
| `name` | string | 是 | 餐點顯示名稱；不可為空字串。 |
| `description` | string | 是 | 餐點簡短說明；沒有說明時使用空字串 `""`。 |
| `price` | integer | 是 | 餐點價格；以新臺幣元為單位，必須是大於或等於 `0` 的整數。 |
| `available` | boolean | 是 | 是否供應；只能使用 JSON 布林值 `true` 或 `false`。 |

## 4. 資料格式規則

1. 檔案必須使用 UTF-8 編碼，且內容必須是有效 JSON。
2. 所有表格中標示為必填的欄位都必須存在，不可省略。
3. `restaurant.name`、分類的 `name` 與餐點的 `name` 不可為空字串。
4. 分類及餐點 `id` 只能由小寫英文字母與連字符組成；不得以連字符開頭或結尾，也不得使用連續連字符。
5. 每個分類 `id` 在整份菜單中必須唯一；每個餐點 `id` 在整份菜單中也必須唯一。
6. `categories` 與 `items` 必須是 JSON 陣列，即使目前只有一筆資料也不可改成單一物件。
7. `description` 必須是字串；沒有內容時保留欄位並填入空字串。
8. `price` 不可使用字串、小數或負數，也不包含貨幣符號。
9. `available` 必須是 JSON 布林值，不可使用 `"true"`、`"false"`、`0` 或 `1` 代替。
10. AI 辨識結果必須先符合本規格，才能成為點餐網站使用的團購菜單快照或店家固定菜單。

## 6. 菜單歸屬與生命週期

- `data/menu.json` 是開發與未串接 AI 時的示範資料，不是所有使用者共同覆寫的正式菜單。
- 團購模式會將本格式的菜單內容保存為該次團購的快照。
- 店家模式會將本格式的菜單內容保存為屬於店家的固定菜單。
- 團購或店家識別碼、團購狀態及管理 Token 不放進本菜單內容格式，應由資料庫另外保存。
- 訂單必須另外保存送單當時的品項名稱與價格，避免菜單更新影響歷史訂單。

## 7. 目前暫時不支援的複雜菜單內容

目前格式刻意維持第一版所需的最小範圍，暫不支援：

- 糖度與冰量選擇。
- 加料與加價選項。
- 大小杯、份量或其他尺寸選擇。
- 套餐組合、套餐換購與多步驟選餐。
- 同一餐點的多種價格或客製化價格。
- 菜單內容本身不保存多店家、多分店或分店限定規則。

如未來確認需要上述能力，應先更新本規格與驗收條件，再調整資料格式。
